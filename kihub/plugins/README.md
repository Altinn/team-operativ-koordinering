# plugins/

Samlepakke som bunter skills, agents, hooks, commands og tools til én
installerbar enhet — distribusjonsformatet for KI Hub. Hver plugin er en mappe
med `plugin.json` som peker på delene.

## Første kandidat: `prosess-som-kode`

Startpakka andre team installerer for å ta i bruk mønsteret (ikke selve
beredskapsdataene, men verktøyene rundt): `endre-rolle`-skill,
doc-regenererings- og valideringshooks, veiviser-assistenten og repo-
instruksjonene. Dette er svaret på «50 snøfnugg»: ett delt mønster, mange
prosesser — ikke én bespoke løsning per prosess.
